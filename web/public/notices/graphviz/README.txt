PDOPT-BN uses unmodified @viz-js/viz 3.31.0 (MIT) as a browser worker dependency.
Upstream: https://github.com/mdaines/viz-js/tree/master/packages/viz
Viz.js wrapper license: viz-js-MIT.txt.

The embedded WebAssembly backend includes Graphviz 16.1.0 (EPL-2.0) and
Expat 2.8.5 (MIT). Corresponding source is available at:
https://gitlab.com/api/v4/projects/4207231/packages/generic/graphviz-releases/16.1.0/graphviz-16.1.0.tar.gz
https://github.com/libexpat/libexpat/releases/download/R_2_8_5/expat-2.8.5.tar.gz
License texts: Graphviz-EPL-2.0.txt and Expat-MIT.txt.
Build provenance and source digests are copied from the package on each build
into build-provenance.json. These dependencies are separate works and do not
change the license of the PDOPT-BN application code.
